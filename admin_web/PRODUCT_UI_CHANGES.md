# Product UI update

Frontend updated to match the backend Product/ProductVariant model.

- Product list now treats Variant as the source of selling price and stock.
- Product list shows thumbnail, category/brand, Variant count, Variant attribute previews, price range, total stock and available stock.
- Product detail has a product summary header and Variant cards for quick visual scanning.
- Variant cards show image, attributes, SKU, price, stock, reserved stock, available stock and active state.
- Variant management/editor remains available below the visual Variant overview.
- Backend API and validation logic were not changed.
